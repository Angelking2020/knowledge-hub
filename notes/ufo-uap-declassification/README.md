## 🧭 名词速查

- **UAP** = Unidentified Anomalous Phenomena，不明异常现象（2023 财年 NDAA 将 Aerial 改为 Anomalous，涵盖空/海/水下/太空/跨介质）。
- **PURSUE** = 战争部主导的官方 UAP 解密门户，2026-05 起滚动发布，截至第四批共约 334 份文件。
- **AARO** = All-domain Anomaly Resolution Office，全域异常解析办公室；PURSUE 各文件的官方描述由其撰写。

## ⚠️ 阅读提示

"Unidentified / Unresolved"意为"（暂）**未解释**"，并不等于"外星/超自然"——档案中相当比例的内容其实指向已知的平淡原因（宇宙射线视网膜光闪、红外传感器伪影、气球、原型机、流星等）。**解密 ≠ 证实**。详见分析正文的"局限与免责声明"。
