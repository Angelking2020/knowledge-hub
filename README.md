# knowledge-hub

> 学习资料与文档分享仓库 —— 公开、可自由转载（署名即可）。

这里整理并分享学习过程中沉淀的笔记、资料和教程，欢迎自取、转载与交流。

## 📂 目录结构

| 目录 | 内容 |
| --- | --- |
| [`notes/`](notes/) | 学习笔记、知识点梳理、读书笔记 |
| [`resources/`](resources/) | 资料汇总：书单、链接、工具、速查表 |
| [`tutorials/`](tutorials/) | 手把手教程、操作指南、实践记录 |
| [`assets/`](assets/) | 图片等静态资源（被上面的文档引用） |

## 🧭 如何使用

- 直接在 GitHub 上点开各目录浏览，Markdown 文档会自动渲染。
- 想离线查看，可以克隆到本地：

  ```bash
  git clone https://github.com/Angelking2020/knowledge-hub.git
  ```
